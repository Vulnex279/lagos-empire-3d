The optional Blender adaptation tools need the downloaded free source archives;
the ready-to-import GLBs are committed, so Blender and downloads are unnecessary
to run, test or export the game. External source archives are not shipped in the
APK. Blender itself is a build tool; its GPL does not relicense artwork exported
from it. Android/JDK tooling retains its upstream terms.

CC0 permits commercial use and modification without attribution; credits are
provided voluntarily. This project remains an original fictional district broadly
inspired by Lagos, not a surveyed reconstruction. No generated concept art is
used as gameplay evidence.
