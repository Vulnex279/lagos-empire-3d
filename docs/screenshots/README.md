# Actual-engine screenshots

Files beginning `upgrade-` are captured from version 0.2.0 by
`tests/capture_upgrade.gd`, using Godot Compatibility/OpenGL, 1280×720, Medium
settings on Mesa llvmpipe. They show real project meshes, lighting, UI and state.
The harness uses temporary funds and positioned cameras to inspect purchased assets.
No concept art, compositing or external rendered models are presented as gameplay.
Older files without the prefix remain as historical version-0.1 evidence.

The photographs do not establish Android FPS or final premium-art acceptance.
